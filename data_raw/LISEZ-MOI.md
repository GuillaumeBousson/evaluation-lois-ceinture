# Données

Les données appartiennent aux auteurs de l'article. Elles ne sont donc pas recopiées dans ce dépôt.

Pour les obtenir :

1. Aller sur la page « Research » de Liran Einav : https://leinav.people.stanford.edu/research
2. Chercher l'article écrit avec Alma Cohen, « The Effects of Mandatory Seat Belt Laws on Driving Behavior and Traffic Fatalities ».
3. Télécharger le fichier « Data Set and Do File » et le décompresser.
4. Placer le fichier `.dta` dans ce dossier, sous le nom `SB_Paper.dta`.

L'étape 0 du script lit ce fichier et enregistre une version préparée dans `data_step0/`. Les étapes suivantes partent de cette version.
